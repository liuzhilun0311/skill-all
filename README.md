# 技能总览 (skill-all)

识别当前智能体环境，完整展示本会话可用的技能、用途和获取时间，按首次获取时间由近到远排序。

英文调用标识是 `$skill-all`，界面显示为“技能总览 (skill-all)”。

## 安装与准备

将完整技能目录放入宿主支持的用户技能目录并刷新。
Codex 使用 `$CODEX_HOME/skills`，未设置时通常为 `~/.codex/skills`。
无需单独安装本技能的运行依赖或配置服务密钥；读取本地时间需要宿主提供文件访问能力。

## 如何调用

无需补充参数：

```text
使用 $skill-all 列出当前全部可用技能。
```

```text
使用 $skill-all 展示技能名称、用途和首次获取时间，
按从近到远排序。
```

这些是在智能体对话中使用的请求，不是安装到终端中的命令。

## 输出

默认直接在对话展示环境、技能数量、时区和一个三列表格：

| 列 | 内容 |
| --- | --- |
| Skill | 技能真实标识，保留插件命名空间 |
| 能做什么 | 中文概括实际用途及重要前提 |
| 技能时间 | 首次获取时间及来源，无法确认时为“未知” |

以当前会话的可用技能清单为优先依据，包括系统和插件技能。
只有磁盘发现结果时，会明确说明“当前会话可用性未确认”，不会把安装目录中的全部文件都视为已启用技能。

## 时间与排序

1. 优先使用含义明确的首次获取字段或可靠首次安装记录。
2. 没有可靠记录时，使用单个技能安装目录的创建时间，并注明“目录创建，近似”。
3. 没有可用依据时显示“未知”，排在可比较时间之后。

普通使用、编辑和升级时间不参与排序。
最近一次 `installed_at` 不自动等于首次安装时间，文件修改时间也不会作为获取时间使用。
目录创建时间可能受复制、迁移、解压或重装影响，不能保证还原历史真实首次获取时间。

优先使用会话时区，完整时间显示为 `YYYY-MM-DD HH:mm`；只有日期的记录不补造时分。
相同实际时间按技能标识稳定排序。

## 操作边界

本技能只读清单、说明和必要时间信息，不运行表中的技能。
默认不安装、更新、删除技能，不联网搜索，也不生成额外文件或改写安装记录。

完整规则见 [SKILL.md](SKILL.md)，界面配置见 [agents/openai.yaml](agents/openai.yaml)。
